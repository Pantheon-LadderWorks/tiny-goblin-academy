# Tiny Goblin Academy Documentation

Welcome to the Tiny Goblin Academy documentation root. This repository contains the architecture, planning, and historical reports for the entire studio ladder.

To keep the root clean, documentation is categorized semantically:

- **`architecture/`**: Broad repository strategies, repo hygiene, and overall distribution architecture.
- **`assets/`**: Asset pantry rules, visual pass plans, and Hub asset organization.
- **`boot/`**: Boot doctrine, product entry standards, and boot screen integration.
- **`evidence/`**: Screenshot and evidence indexes.
- **`hub/`**: Hub concepts, scaffold plans, and contracts.
  - **`hub/reports/`**: Historical H1/H2/H3 completion reports and visual passes.
  - **`hub/runtime/`**: Launcher, runtime, Tauri, and bridge contracts.
- **`incidents/`**: Loss reports, refactor incidents, and reconstruction plans.
- **`manifests/`**: Manifest strategy and catalog truth docs.
- **`methodology/`**: Curriculum, loop-first protocol, and lessons synthesis.
- **`roadmap/`**: Phase and tier planning docs.
- **`workspace/`**: Dependency handling, installer audits, package census, and W-phase (Workspace) reports.
